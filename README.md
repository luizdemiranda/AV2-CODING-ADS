# AV2 – Controle de Estoque

Avaliação prática individual em JavaScript (ADS – Coding).

Programa para uma papelaria conferir se um pedido pode ser atendido e calcular quantas unidades sobram depois da venda.

## Arquivos

- `diagnostico.js`: investigação do erro inicial (Etapa 1)
- `estoque.js`: funções `podeAtenderPedido` e `estoqueAposVenda`, com os testes
- `registro.md`: registro do que foi observado, alterado e conferido

## Como executar

    node estoque.js
    node diagnostico.js
